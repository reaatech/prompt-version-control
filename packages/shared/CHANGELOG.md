# @reaatech/prompt-version-control-shared

### Initial release

- Canonical TypeScript types for prompts, versions, tags, evaluations, metrics, and deployments
- Zod schemas for all API request/response payloads
- Utilities: `calculateChecksum`, `generateApiKey`, `hashApiKey`, `sleep`, `renderTemplate` (Handlebars)
- `zod` is a required peer dependency — install it alongside this package
